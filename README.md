# Bikepark St Éloi

Jeu de VTT 3D sur la piste bleue Gravity du Bikepark St Éloi (La Ville-du-Bois, Essonne), fait avec Godot 4.

**Jouer : https://thomeunier-art.github.io/bikepark-st-eloi/**

Sur iPhone, pour le plein écran : dans Safari, Partager ▸ « Sur l'écran d'accueil », puis lancer le jeu depuis son icône, en paysage.
